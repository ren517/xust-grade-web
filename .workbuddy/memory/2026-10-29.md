# 2026-10-29

## 课表三大新功能（周切换 / 开始时间 / 期末考试安排）

### 新增文件
- `core/exam.py`：考试安排爬虫与缓存。移植自 CLI 项目 `XUST-Grade-Inquiry-System/exam.py`，接口 `POST kwgl/kscx_cxXsksxxIndex.html?doType=query&gnmkdm=N358105`。
  - `fetch_exam()` / `save_exam()` / `load_exam()` / `get_exam()`：缓存到 `data/exam_{xh}.json`，与课表同构。
  - `parse_time()`：`"2026-06-25(14:00-16:00)"` → `("2026-06-25", "14:00-16:00")`。
  - `format_teachers()`：`"001344/罗清郁;000850/刘文刚"` → `"罗清郁、刘文刚"`（自动去工号）。
  - `normalize()`：原始 items → 模板友好结构（course/time_text/date/range/place/seat/credit/college/teachers/method/campus/exam_name），并按考试时间排序。
  - 字段映射：ksmc考试名称 xnmc学年 xqmmc学期 xqmc校区 kcmc课程名称 khfs考核方式 xf学分 kssj考试时间 cdbh考场 zwh座位号 kkxy开课学院 jsxx教师。

### 修改文件
- `core/schedule.py`：`semester_start(override=None)` 与 `current_week(today, start=None)` 支持外部传入开学日期；新增 `max_week(kb_list, default=20)` 从 zcd 解析最大周次。
- `app.py`：
  - 新增 `_load_settings/_save_settings/_semester_start/_set_semester_start`（持久化到 `data/settings.json`，按学号隔离，优先级 session > 文件 > config.SEMESTER_START）。
  - `GET /schedule` 支持 `?w=N`；下发 `weeks_data`（全部周次网格，供前端免请求切换）、`sel_week/max_week/semester_start/exams/exam_synced`。
  - 新增 `POST /schedule/start`（设置/恢复课表开始时间，含空值与日期格式校验）与 `POST /exam/update`（爬取考试安排，学年学期优先跟随课表缓存）。
  - 首页 `/` 的周次也改用 `_semester_start(request)` 保持同步。
- `templates/schedule.html`：横向滚动周次条 `.week-tabs` + 上下周按钮（前端 `setWeek()` 用 weeks_data 重渲染，滚轮竖向转横向）；「课表开始时间」日期表单；底部「期末考试安排」板块（考试时间/地点/科目 chip + 点击展开学分/考场/座位号/考核方式/开课学院/监考教师/校区/学年学期）。
- `static/css/style.css`：新增 `.start-form/.sf-*`、`btn-sm`、`.week-tabs/.wtab/.wn-btn`、`.exam-card/.exam-detail/.ed-*`，沿用现有设计令牌。
